Sets: trips s (L1: n1 out + n1 in, L2: n2 out + n2 in, L3: n3 each way). T = 60.
Variables: x_s ∈ {0..59} departure minute at origin terminal; h_s ∈ [2,4] halt at VDLR (Line 3);
 p ∈ Z (modulo wrap, one per constraint); y_ad ∈ {0,1} arrival a → departure d link; w_ad turnaround time; N ∈ Z fleet.
Running times: CSMT–VDLR 17, VDLR–PNVL 63, VDLR–ADH 25 (event time = x_s + offset).

min N
(1) Frequency: sort x of each line/direction; gaps x_{k+1}-x_k ∈ [lo,hi] (and cyclic wrap 60 + x_1 - x_n).
(2) Track headway, for every pair (u,v) of trains entering the same track in the same direction:
      3 ≤ (x_v + o_v) − (x_u + o_u) + 60·p_uv ≤ 57
(3) Turnaround at terminal r (CSMT: exactly 3; PNVL, ADH: 5..10):
      Σ_d y_ad = 1 ∀ arrivals a,  Σ_a y_ad = 1 ∀ departures d
      dep_d − arr_a + 60·q_ad − w_ad = 0  if y_ad = 1 (big-M),   lo·y ≤ w ≤ hi·y
(4) Fleet: Σ running times + Σ w_ad + Σ h_s = 60·N   (vehicle-minutes per hour = 60 × rakes)
Rake rosters = cycles of the arrival→departure links y; a roster of length 60·m is run by m rakes spaced one hour apart.
